## 0. 本次诊断改变了什么

两份文档此前都默认「从零自训的模型是当前线上主后端」，本轮实测发现一个被忽略的关键事实：

> **仓库里一直躺着一个现成模型 `models/minej-bert-personality`（即 README 原设计的 `Minej/bert-base-personality`），前四轮实验从没拿它当过基线。**

三后端在锁定测试集（N=10 作者）上的作者级表现：

| 后端 | 作者级 r≥0.35 | 平均 MAE | 冒烟区分度（关键） | 判定 |
|------|--------------|----------|-------------------|------|
| 自训 psych-personality-bert（MLM 域适应） | 1/5（E +0.499） | 0.278 | **几乎没有**（外向句/焦虑句输出几乎相同） | 已退化为均值预测，**死亡** |
| 现成 minej-bert-personality（sigmoid） | 0/5 | 0.284 | **有**（E 0.50 / N 0.55 等有区分） | 活，原设计基线 |
| 启发式 | 0/5 | 0.283 | **有**（worry→N 0.6，finish→C 0.58） | 可解释兜底 |

### 两个决定性的判断

1. **N=10 的作者级 Pearson 不能用来选模型。** 三个后端在 10 人上都过不了 3/5，符号乱跳（自训 E 正、Minej E 负、启发式 C 负）。这是测试集太小，不是模型优劣的信号。

2. **「冒烟区分度」才是可观察的硬指标。** 同样的两句反差文本，自训模型输出几乎全等（模型死了），Minej 和启发式都能区分。**继续在 99 作者上自训没有意义，但线上还挂着这个"死"模型是有害的——英文 0.7 权重会把每个用户画像拉向同一组均值。**

## 1. 行动方案（按优先级重排）

### Phase 0 —— 三后端诊断（已完成 ✓）

- 现成 Minej：sigmoid 输出、标签顺序 `E,N,A,C,O` 与代码 `MINEJ_LABELS` 完全一致，官方模型卡确认 `sigmoid(logits)`。
- 自训模型：冒烟退化为常量，判定不可当线上主后端。
- 启发式：可解释、有词级区分度，作为兜底。

### Phase 2' —— 线上止血（立即，可执行，替代原 Phase 2）

原 Phase 2 只想到「降 BERT 权重靠启发式」。本轮发现更优的分支：**切换到 Minej（活的）而非继续用死模型，同时保守降权重**。

步骤：
1. 线上后端从自训模型切到 `minej-bert-personality`（调整 `_find_local_model_dir` 顺序，或显式 `PERSONALITY_MODEL_PATH`）。
2. 英文 BERT 权重 `0.7 → 0.4`、中文 `0.35 → 0.2`（作者级仍不达标，不配给高权重），主靠启发式。
3. 加「实验性功能」标注 + README/API 文档说明小样本背景。
4. 冒烟测试：外向/焦虑/尽责三组句子必须能区分，且不再命中死模型常量。

验收：冒烟三组句子分数有区分度；`/v1/users/<id>/personality` 返回的 `model.backend` 不再是死模型量化值。

### Phase 2.5' —— 迁移学习热启动（已跑，未达标 ★）

应「实在不行就重写训练策略重跑」尝试了与冷启不同的路线：从现成 minej（活模型）热启动、保留分类头，两阶段微调后再测锁定测试集。

- Stage 1 只训分类头（冻结全部 BERT）：val 作者级 r **-0.125**。
- Stage 2 解冻后 2 层：val 作者级 r **-0.132**，随后往 -0.26 恶化，早停。
- 锁定测试（N=10）：**1/5** 维 r≥0.35（agreeableness +0.365，p=0.30），作者级平均 MAE **0.2956**。
- **未达标**。变更初始化/loss/freeze 不改变结论，坐实 99 作者监督信号不够估作者级 Pearson。

产出 `models/psych-personality-bert-transfer` 不上线；回归测试 33 passed。

### Phase 1 —— 数据救济（关键路径）✅ 已完成

- **已拿到 PANDORA 官方全量**：HuggingFace `jingjietan/pandora-big5`（Apache-2.0，约 300 万条 Reddit 评论，**1548 个唯一五元组 ≈ 作者数**）。
- 标签是 O/C/E/A/N 连续分数（0–100，0.1 精度），比本地旧 99 作者子集（0–99 整数）更完整；`ptype` 32 类 MBTI/人格在每个作者内恒定，可用于作者级分层。
- **官方 train/val/test 有作者级泄漏**（test 1481 作者中 1455 个也出现在 train），系按评论行随机切所致，不能直接用；已用 `GroupShuffleSplit` 按作者重切 70/15/15。
- 清洗后：1432 作者 / 101877 条 → **train 1002 / val 215 / test 215 作者，作者级零泄漏**。
- 备选 `jingjietan/essays-big5`（2467 篇意识流长文本，0/1 二值标签）留作泛化验证，非主数据。
- 验收达成：**≥300 作者、测试 ≥50 作者**（实际 215 测试作者）。

### Phase 3 —— 全量重训（首轮完成，待多 seed 确认）

数据到位后，瓶颈从「样本量」转到「别把 1548 作者又训塌」。新脚本 `scripts/train_pandora_full.py` 落地了全部 P0/P1 要求：

- 数据：`scripts/prepare_pandora_full.py` 下载并按作者重切（70/15/15，锁死测试作者集合）。
- 基座：`Minej/bert-base-personality` 热启动（活模型 + 标签顺序对齐），非冷启。
- 损失：加权 Huber（δ=0.1），权重 = 各维标签 std 倒数；标签归一化 `/100`（旧是 `/99`）。
- 优化：AdamW 分组 lr（头 5e-4 / backbone 2e-5）+ **warmup 10% + cosine** + **梯度裁剪 1.0**（P0）。
- 动态 bag：**每 epoch 从作者全部评论重抽 16 条**（P0 数据增强），bag-mean → sigmoid。
- 两阶段：Stage 1 冻结全部 BERT 只训头（freeze_below=12），**val Fisher-z 平均 r 连续 2 epoch 不升即进 Stage 2**（P0 切换条件）；Stage 2 解冻后两层（freeze_below=10）。
- 早停主指标：**作者级 Fisher-z 平均 r**（P1），同时按维记录，防止平均数掩盖单维崩坏。
- 双基线（P1）：(a) 训练集均值常量预测；(b) 冻结 BERT 平均 embedding 线性探针。最终打不赢 (a) 即判失败。
- 冒烟量化闸门（P0/P1）：反差句子预测差 |Δ|<0.05 判退化；训前只记录（minej 单句方向本弱），训后作硬闸门。
- 多 seed + bootstrap 置信区间（P1）：作者级指标在作者块上重采样。
- 达标口径不变：≥3/5 维作者级 r≥0.35 且平均 MAE<0.12。

**首轮结果（seed=42）**：

| 维度 | 作者级 r | 作者级 MAE |
|------|----------|------------|
| extraversion | +0.222 | 0.270 |
| neuroticism | +0.263 | 0.274 |
| agreeableness | +0.272 | 0.249 |
| conscientiousness | +0.151 | 0.240 |
| openness | +0.142 | 0.275 |
| Fisher-z 平均 | **+0.211**（95% CI [0.15, 0.27]） | 0.262 |

- **0/5 维 r≥0.35，平均 MAE 0.262，未达标。**
- 历史性进展：五维 r **首次全部转正**（之前的 99-author 数据全在 ±0.4 乱抖）。
- 双基线：均值预测 r=0/MAE 0.273；线性探针 r=**+0.243**/MAE 0.270。微调 r=+0.211 打赢均值基线，但**输给线性探针**。
- 冒烟闸门捕获到 conscientiousness 维退化（训后 C 反差句差仅 0.034 < 0.05），尽管其 r 仍有 +0.151。
- **判断**：增益主要来自 minej 表示，微调略过拟合；MAE<0.12 与标签固有 std≈0.3 矛盾，回归路线的 MAE 大概率到顶。建议下一步：补跑 seed=7,123；考虑直接用线性探针做后端；重估 MAE 达标线。

## 3. 决策点

- **现在**：执行 Phase 2'（切 Minej + 降权重），止血死模型。
- **Week 2 末**：若新数据 ≥300 作者 → Phase 3；否则停训，维持 Phase 2' 降级方案，或考虑砍功能。

一句话：**不再在 99 作者上反复调参；先把线上死模型换成活的 Minej 并降权，把精力投向拿全量数据。** 迁移学习热启动已实测同样撞在 99 作者天花板上，进一步印证此结论。
