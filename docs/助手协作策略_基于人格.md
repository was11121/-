# 助手协作策略设计：基于人格画像的优劣发扬与任务增效

> 依据 `docs/深度研究报告_人格互补_v2.md` 的 10 轮证据与 `personality_runtime/traits.py` 机制，将“0-1 五维分”转化为可执行的助手行为规范。目标：**扬长（让优势更高效）+ 补短（让缺陷不踩坑）+ 任务得心应手（按人格给不同的任务脚手架）**。

## 1. 设计原则（与报告 §6 对齐）

1. **不贴标签，只给动作**：对外不输出“你是高神经质”，只说“压力大时我们先用 25 分钟丑第一版起步”。
2. **倒U约束**：`E/A/C` 越高不是越好，`0.55±0.10` 为团队贡献甜点，超出则加约束而非激励。
3. **Facet 分流**：`C` 按 `成就/自律` vs `秩序/审慎` 给不同脚手架，`O` 按 `观念/行动` 分流。
4. **情境感知**：强情境（看板已建、流程卡死）少人格化，弱情境（自由聊天、模糊目标）重人格化。
5. **可关闭可遗忘**：所有督促带 `confidence/cooldown/dismissible`，支持 `忘/拒` 回流。

## 3. 衍生风格的任务脚手架

| 衍生 | 画像 | 助手脚手架 |
|---|---|---|
| **思维倾向** `rational ≥0.58 理性` | 看证据步骤 | 给优先级、截止、取舍表，少空泛鼓励 |
|  | `affective ≤0.42 感性` | 先处理愿不愿开始，再给方法；用更小更具体动作 |
| **执行倾向** `executor ≥0.58` | 执行型 | 守优先级防过载，每日只核对主任务 |
|  | `procrastinator ≤0.42` | 最小下一步+25分钟+短截止，每完成一步即时肯定 |
| **社交/边界** `social high / boundary overcommit` | — | 高E保护专注，高A守主任务，低A/E 强制外化与同步 |

## 4. 任务全生命周期：助手如何介入

```
用户意图 → 识别人格+任务类型 → 选策略 → 生成脚手架 → 执行中轻推 → 复盘强化
```

**① 任务创建时**：若 `低C` 则自动重写标题为可开始动作（“写报告”→“新建 3 行提纲”）；若 `高O` 则加“探索/收敛”双阶段标签。

**② 任务进行中**：`高N` 每 25 分钟检查一次焦虑词，触发“丑第一版”安抚；`高E` 专注块内屏蔽非紧急 @；`高A` 新请求自动做“挤掉主任务”冲突检测。

**③ 任务卡住时**：`低E/低A` 超 25 分钟无进展 → 推送“外化提问模板”；`低C` 推送“环境重构”建议（关通知、清桌面）。

**④ 任务收尾时**：`高C` 自动邀复盘（“本次 3 个做得好/1 个可改进”），`高O` 邀“经验沉淀为模板”，`低N` 邀“给团队一句同步”。

## 5. 组合画像的协同剧本（4 典型）

**剧本1：创意发散者（高O低C高N）** 助手角色 = **收敛教练**。每日只允许 1 个探索分支，其余入“想法池”；所有任务以 2 分钟启动；高N 用清单去焦。

**剧本2：稳健执行者（低O高C低N）** 助手角色 = **流程守护**。复用模板，变更单变量，里程碑核对，给“是否需同步”提醒，避免团队误读。

**剧本3：社交粘合剂（高E高A中C）** 助手角色 = **边界守门人**。保护专注块，主任务置顶，新请求延后队列，讨论必转补丁。

**剧本4：理性双高（高O高C低N）** 助手角色 = **目标留径**。对秩序高者给路径，对成就高者给终点，探索设盒但不扼杀，交付后强制复盘防过载。

## 8. 验收标准

- 同一用户跨 Web/QQ 画像一致，`samples≥5` 才显画像
- 低C 任务首步时间 <2 分钟可开始，高N 任务首稿允许不完美
- 高E 专注块内无打扰，高A 新请求必做冲突检测
- 7 天内 `adoption_rate>0.5` 且 `forget_rate<0.1`，14 天复测有 0.03-0.06 分位移即达标

> 本设计将深度报告的“证据”翻译为“行为”，让助手不再是统一话术的复读机，而是按人格给不同脚手架的协作者。
