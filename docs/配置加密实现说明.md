# 运行时配置加密实现说明

> 本文档说明本项目中「服务区上游连接」与密钥的加密、脱敏与防逆向实现。
> 该文件已在 `.gitignore` 中排除，**不会随 Git 提交**，仅供本地查阅。

---

## 1. 要保护什么

项目把两批敏感数据放进运行时配置（前端「服务配置」热更新落盘）：

| 类别 | 字段 | 说明 |
|---|---|---|
| 密钥 | `MODEL_API_KEY` / `TAVILY_API_KEY` / `MCP_API_KEY` / `WEB_RELAY_SSH_KEY` | LLM / 联网 / MCP / SSH 凭据 |
| 上游连接 | `SEARXNG_URL` / `JINA_READER_URL` / `WEB_RELAY_SSH_HOST` / `WEB_RELAY_SSH_USER` | 服务器侧上游服务地址与主机 |

目标：

1. **对用户不显示**：任何通过 Web 控制台登录的用户（含管理员）都看不到上游地址、主机、密钥明文。
2. **存储加密防逆向**：配置文件里不以明文出现这些字段，键名混淆，文件名不含敏感关键字。
3. **接口脱敏**：对外接口只给「已配置 + 掩码提示」，不返回完整值。

---

## 2. 配置文件与磁盘形态

- 落盘文件：`<MYAGENT_DATA_DIR>/.runtime.bin`
  - 文件名不含 `settings` / `config` 等关键字，避免被一眼定位。
- 文件内容是 JSON，但键名全部混淆成短键（见第 5 节映射表）。
- 敏感字段的值以 `enc::` 前缀开头，后跟加密后的 base64；非敏感字段（如 `WEB_BACKEND`）仍是明文短键值。

磁盘示例（实际保存内容）：

```json
{
  "wb": "mcp",
  "wu": "http://127.0.0.1:8093",
  "su": "enc::MwUXKLjbOqDQdSw7ngtu1lPFPayYtnwV2w2FtHjAhd61ZOH1Dj2olpsTRZzF0ccZ2jsK4J6sukPYxmTIBg==",
  "tk": "enc::ihHN5CrVrC0F7ZigKZNnec5h83CLO5iH+L1PSwUOtmRF26lbNQ1BBvAguNV2ow==",
  "mk": "enc::/pedy2pKRXvxSesflESnFEG1auQMbc9VUcVZO/wUo9/L7MSILCU="
}
```

- 没有 `TAVILY_API_KEY`、`SEARXNG_URL` 这类原键名。
- 没有 `tvly-...`、`http://searx.internal...` 这类明文值。
- `.runtime.bin` 与加密主密钥文件 `.settings_key` 都在 `.gitignore` 中（`.gitignore` 内含 `.runtime.bin`、`.settings_key`、`*.bin`）。

## 3. 加密算法与密钥管理

### 3.1 算法

- 首选：**AES-256-GCM**（`cryptography` 库的 `AESGCM`，带随机 nonce，提供机密性 + 完整性认证）。
  - 每个值加密时生成 12 字节随机 nonce，`nonce + ciphertext` 一起 base64 后存盘。
  - 相同明文每次加密结果不同（nonce 随机），无法通过比对密文推断。
- 兜底：未安装 `cryptography` 时退化为「主密钥 XOR + base64」，避免纯明文落盘，但强度低于 AES，**生产环境应安装 `cryptography`**。

### 3.2 主密钥来源（优先级从高到低）

1. 环境变量 `RUNTIME_SETTINGS_KEY`（推荐生产设置一个强随机口令/32 字节）。
   - 若长度正好 32 字节 → 直接作为 AES 密钥。
   - 否则对口令做 `SHA-256` 得到 32 字节密钥。
2. 未设置时：自动生成 32 字节随机密钥，base64 后写到 `<MYAGENT_DATA_DIR>/.settings_key`（权限 0600，仅当前用户可读写）。
   - 注意：如果 `.settings_key` 丢失，历史上用该密钥加密的值**无法解密**，只能重新配置。

### 3.3 解密失败行为

`_decrypt_secret` 对无法解密的值返回空字符串（不抛异常），避免因密钥缺失/被篡改导致服务崩溃。

## 4. 加密/解密流程

```
保存 (save_raw):
  原键名 dict ({'TAVILY_API_KEY': 'tvly-xxx', ...})
    → 过滤：仅 KNOWN_KEYS、密钥留空不修改
    → 混淆键名：TAVILY_API_KEY → tk
    → 敏感值加密：tk = "enc::" + AESGCM(key, nonce, value)
    → 写 .runtime.bin

读取 (load_raw):
  .runtime.bin
    → 反混淆键名：tk → TAVILY_API_KEY
    → 识别 enc:: 前缀 → AESGCM 解密 → 内存中还原明文
    → 返回原键名 dict（明文只出现在内存，不落盘）

对外 (effective):
  原键名 dict
    → SECRET_KEYS / UPSTREAM_HIDE_KEYS → {"configured": bool, "hint": "****尾4位"}
    → 非敏感字段 → 明文值
```

`apply_to_environ` 把配置写回 `os.environ`，供 LLM / MCP client 热读取（与启动时 `.env` 同语义）。

## 5. 键名混淆映射表

磁盘短键 ⇄ 原键名（`SETTINGS_KEY_MAP` / `_REVERSE_MAP`）：

| 原键名 | 短键 |
|---|---|
| `BASE_URL` | `b` |
| `CURRENT_MODEL` | `m` |
| `MODEL_API_KEY` | `k` |
| `MEMORY_BACKEND` | `mb` |
| `MEMORY_MCP_URL` | `mu` |
| `MCP_API_KEY` | `mk` |
| `MEMORY_MCP_TIMEOUT` | `mt` |
| `WEB_BACKEND` | `wb` |
| `WEB_MCP_URL` | `wu` |
| `WEB_MCP_TIMEOUT` | `wt` |
| `SEARXNG_URL` | `su` |
| `TAVILY_API_KEY` | `tk` |

## 6. 对外接口的脱敏行为

| 接口 | 行为 |
|---|---|
| `GET /v1/admin/settings` | 密钥与上游字段 → `{"configured","hint"}`；只有 `WEB_MCP_URL` / `BASE_URL` / `WEB_SEARCH_TIMEOUT` 等普通配置返回明文 |
| `POST /v1/web/search` | `channel` 中性化：`searxng→本地引擎`、`tavily→在线引擎`、`tavily-relay→中转引擎` |
| `POST /v1/web/fetch` | `via` 中性化：`jina-direct→网页解析`、`jina-relay→网页解析(中转)` |
| `GET /v1/web/info` | 仅管理员可访问，返回布尔状态（`searxng_configured` 等），不含任何 URL/主机 |
| `POST /v1/admin/settings/test` | 支持 `target=searxng/tavily/jina/llm/memory_mcp/web_mcp`，只返回 ok/error，不回显配置值 |
| `mcp_web /health` | 只返回通道布尔状态，不回传上游地址 |
| `mcp_web web_info` 工具 | 明确剥离 `searxng_url` / `jina_reader_url` / `relay_host` / 所有密钥 |

前端「服务配置」页（仅管理员可见）里上游字段显示为密码框，回显空白，只显示 `(已配置 ****xxxx)` 提示；保存时留空表示「不修改」。

---

## 7. 防逆向的层次总结

| 层次 | 手段 |
|---|---|
| 存储 | AES-256-GCM 加密敏感值 + 键名混淆 + `.runtime.bin` 文件名 |
| 传输/接口 | 响应脱敏（掩码 hint、channel/via 中性标签） |
| 权限 | `/v1/web/info` 仅 admin；服务配置页仅 admin 可见 |
| 分发 | 上游密钥只留在服务器 `mcp-web` 环境，不随 Agent 分发（`.env` 不提交） |

---

## 8. 运维注意事项

1. **生产一定要自己设 `RUNTIME_SETTINGS_KEY`**（`.env` 里一行强随机值），不要依赖自动生成的 `.settings_key`。
2. `.settings_key` 和 `.runtime.bin` 不要手动删除（删除 = 上游/密钥需重配）。
3. 升级到带 `cryptography` 的环境：旧 XOR 加密值**读不回**（兜底格式 `x1:` 无法用 AES 解），需重新保存一次配置迁移。
4. 本模块在 `storage/runtime_settings.py`，入口为 `save_raw` / `load_raw` / `apply_to_environ` / `effective`。
