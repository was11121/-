# Remedy 演示视频大纲与讲解稿

建议总时长 **3-4 分钟**（比赛评委通常没耐心看长视频，控制节奏比堆功能更重要）。录制建议：屏幕录制 1080p + 口播，或口播配字幕；讲话语速放慢，每个功能点停留 3-5 秒再切换。

## 二、逐段讲解稿（可直接照读，括号内为操作提示）

### 1. 开场钩子（0:00–0:20）
> "现在几乎每个人都在用 AI 聊天，但你有没有发现：每次打开对话框，AI 都不记得你是谁，你说过的计划、你正在做的事，聊完就忘了。我们做了 Remedy——一个真正'记得你'、并且能帮你把想法落地成现实变化的智能体。"

（画面：项目封面 / Logo，可叠加一句字幕："AI 助手，从'回答问题'到'陪你把事做成'"）

### 2. 问题与定位（0:20–0:50）
> "市面上的 AI 助手大多是一次性问答工具：不记得历史、不了解你的习惯，也没法验证'你说要做的事'到底有没有真的完成。Remedy 的核心思路很简单：让 AI 具备三样东西——**长期记忆**、**对你的理解**、和**对现实变化的可追踪确认**。接下来我用几分钟带大家看它是怎么工作的。"

（画面：可用一张简单的文字卡列出三个关键词：长期记忆 / 人格理解 / 现实补丁）

### 3. 记忆自动沉淀（0:50–1:20）
> "打开控制台注册一个账号，直接开始对话。我随口说一句我的习惯和目标——'我周末喜欢跑步，跑完喜欢喝咖啡'。不需要任何额外操作，Remedy 会自动从这句话里提取出记忆点，打上类别和置信度，存进我的记忆库。下次再聊天，它就已经知道这些信息了，不用我重复交代。"

（操作：在对话页输入一句包含偏好/身份的话，切到「记忆与画像」展示新增的记忆条目，指出置信度、类别字段）

### 4. 3D 记忆图谱（1:20–1:50，本次新增亮点，建议给足时间）
> "记忆多了以后，光看列表很难感知'这些记忆之间是什么关系'。我们这次新加了一个 3D 记忆图谱：相同证据来源的记忆会被连成一条线，同类目的记忆也会按置信度串联起来，整张图可以自由拖拽旋转。点开任意一个节点，能看到这条记忆的详情和置信度。这不是摆设，它是真实的后端图结构计算——同一句话推导出的多条记忆、同类目记忆之间的关联，都是实时生成的。"

（操作：切换到「记忆图谱」Tab，展示 3D 图谱旋转/缩放，点击一个节点弹出详情面板）

### 5. 人格画像与督促建议（1:50–2:20）
> "Remedy 还会从对话风格里估计大五人格——开放性、尽责性、外向性、宜人性、神经质。但这不是用来让 AI'扮演'某种性格，而是用来决定'今天该督促我做什么、该发挥我的什么长处'。比如系统判断我执行力容易波动，就会给出更具体、分步骤的提醒，而不是笼统地说'加油'。"

（操作：展示人格雷达图和 coaching 建议卡片）

### 6. 项目秘书 / 现实补丁（2:20–2:50）
> "如果我在对话里同步一项工作进展，比如'接口联调完成了'，Remedy 不会直接帮我改状态，而是生成一条待确认的'现实补丁'草稿。我确认之后它才正式落到项目看板；如果确认错了，还可以一键回滚。这个设计是为了让 AI 永远不会'自作主张'替我改变现实状态，同时保留完整的操作记录。"

（操作：触发一条补丁草稿，展示确认按钮和回滚按钮，看板状态变化）

### 7. AI 图书馆（2:50–3:10，简短带过）
> "另外 Remedy 支持上传自己的 PDF、Word、PPT 文档，建立私有知识库，回答会带上引用来源，避免模型瞎编。"

（操作：上传一份文档，提问并展示带引用的回答，2-3 秒即可切走）

### 8. 技术方案与完成度（3:10–3:30）
> "技术上，Remedy 后端用 Python + Flask，数据默认 SQLite，生产环境一键切换 PostgreSQL；前端是原生 JS 控制台，图谱用 three.js 做 3D 渲染；大模型默认接 DeepSeek，没配置密钥时会自动降级到本地规则响应器，所以核心功能离线也能完整演示。项目自带 Docker 一键部署方案，也有完整的自动化测试覆盖核心链路。"

（画面：可放一张简单架构图或截图轮播）

### 9. 收尾（3:30–3:50）
> "以上就是 Remedy 的核心能力：记住你、理解你、并且帮你把想法落地成可追踪的现实变化。代码完全开源，README 里有一键启动和部署说明，欢迎大家运行体验，谢谢。"

（画面：展示 GitHub 仓库地址 + 启动命令截图）

## 三、录制小贴士

- 提前登录好一个账号并清空/准备好演示数据，避免现场卡在注册验证码或空数据的尴尬。
- 3D 记忆图谱前提前多聊几句，保证图谱里至少有 5-8 个节点，视觉效果更好。
- 每个 Tab 切换后停留至少 2 秒再开始讲解，方便剪辑时对齐画面和口播。
- 如果口播容易紧张，可以先按讲解稿录音频，再对着音频录屏幕操作，最后合成。
- 结尾展示仓库链接时，确保仓库当时是 **Public** 状态（务必在录制前检查一遍，私有仓库评委打不开）。
